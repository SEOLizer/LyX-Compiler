### WP-A3: Struct-Feld `at(offset)` ⬜

**Ziel:** Exakte Offset-Kontrolle für MMIO, Protokoll-Frames, hardware-nahe Structs.

```lyx
type UART_Regs = struct {
  DR:  uint32 at(0x00);
  SR:  uint32 at(0x04);
  BRR: uint32 at(0x08);
  CR1: uint32 at(0x0C);
}
```

**Zu implementieren:**

1. **Parser:** `at(expr)` als optionaler Suffix nach dem Feldtyp. Flag `FIELD_FLAG_PACKED_OFFSET` in `NK_FIELD_DECL.iVal`. Bits [32:63] = Offset-Wert.
2. **Sema:** ConstExpr-Prüfung, Überlappungsprüfung, aufsteigende Reihenfolge (Warnung), Gesamtgröße = max(Offset + sizeof(Field)).
3. **Codegen:** Expliziten statt berechneten Offset bei Feld-Zugriff verwenden.

**Akzeptanzkriterien:**
- `offsetof(UART_Regs, BRR)` = 8
- Überlappende Offsets → Compile-Fehler
- `@packed` Struct → `sizeof` ohne Padding

### WP-A4: `@big_endian` Byte-Swap-Emission ⬜

**Ziel:** Felder mit `@big_endian`-Annotation erzeugen automatisch Byte-Swap-Instruktionen.

```lyx
type IPv4Header = struct {
  @big_endian total_len: uint16;
  @big_endian src_ip:    uint32;
}
var hdr: IPv4Header;
hdr.total_len := 1500;   // emittiert: mov + bswap
```

**Zu implementieren:**

1. **Parser:** `@big_endian` als Feld-Annotation. Setzt `FIELD_FLAG_BIG_ENDIAN` in `NK_FIELD_DECL.iVal`.
2. **Codegen x86_64:** Nach `irLoad`: `BSWAP rax` (uint32/64), `XCHG al, ah` (uint16). Vor `irStore`: analog.
3. **Codegen ARM64:** `REV16` / `REV32` / `REV64`.
4. Einschränkung: nur auf Integer-Felder (`uint8`–`uint64`). `f64`-Feld → Compile-Fehler.

**Akzeptanzkriterien:**
- Round-trip: `hdr.src_ip := x; var y := hdr.src_ip;` → `y == x`
- `BSWAP` im disassemblierten Binary sichtbar
- Annotation auf `f64`-Feld → Compile-Fehler

### WP-A5: ARM64 libc init fix ⬜

**Ziel:** ARM64-ELF-Binaries rufen `__libc_start_main` korrekt auf statt direkt in `main()` zu springen, damit `atexit`, Thread-lokale Variablen und C-Stdlib-Initialisierung funktionieren.

**Zu implementieren:**

1. CRT-Start-Code am Anfang von `_start` emittieren:
   ```
   adrp x0, main@PAGE; add x0, x0, main@PAGEOFF   // argc aus Stack
   // __libc_start_main(main, argc, argv, init, fini, rtld_fini, stack_end)
   bl __libc_start_main@PLT
   ```
2. `__libc_start_main` als externe PLT-Funktion registrieren.
3. Optionaler `--no-libc-init`-Flag für statische Bare-Metal-Targets.

**Akzeptanzkriterien:**
- ARM64-Dynamisch-gelinktes Binary läuft ohne `SIGILL` beim Start
- `atexit`-Handler wird aufgerufen
- Statische Binaries unverändert (kein Regressionsfehler)

## Phase B — Safety-Features (Aerospace-Alleinstellungsmerkmale)

---

### WP-B1: Triple Modular Redundancy (`@redundant`) ⬜

**Ziel:** Mit `@redundant` annotierte Variablen werden dreifach im Speicher gehalten. Lesezugriffe führen automatisch Majority-Voting durch; erkannte Bit-Flips werden selbst-geheilt (SEU-Schutz).

```lyx
@redundant var sensorValue: int64 := 0;
```

**Zu implementieren:**

1. **Parser:** `@redundant` als `var`-Annotation. Setzt `VAR_FLAG_REDUNDANT` in `NK_VAR_DECL.iVal`.
2. **Sema:** Drei Speicher-Slots reservieren (Offsets `base`, `base+8`, `base+16`). Typ-Eintrag mit `TY_REDUNDANT`-Flag.
3. **IR-Lowering:**
   - Schreiben: jede Zuweisung → drei `irStore`-Instruktionen
   - Lesen: `irCall __tmr_read(a, b, c)` → Majority-Wert + Self-Heal
4. **`__tmr_read` Builtin** — Inline in jedem Backend:
   ```
   if a==b → return a (heal c if c!=a)
   if a==c → return a (heal b if b!=a)
   if b==c → return b (heal a if a!=b)
   else    → return a  // triple mismatch
   ```
   x86_64: 3 CMP + 2 CMOV + 1 MOV. ARM64: analog mit CSEL.
5. **Einschränkungen v1.0.0A:** nur skalare Integer (`int64`, `int32`, `int8`). Keine Arrays/Structs. Kein Thread-Safety.

**Akzeptanzkriterien:**
- `@redundant var x: int64 := 5;` belegt 24 Bytes statt 8
- `poke64(addr+8, 0xDEAD)` korrumpiert Kopie 2 → nächster Leseaufruf gibt 5 zurück und hat Kopie repariert
- Normale Variablen: keine Performance-Regression

---

### WP-B2: Secure Post-Patching (`.meta_safe`) ⬜

**Ziel:** Kompilierte Binaries enthalten eine `.meta_safe`-Section mit CRC32-Hashes aller `.text`-Seiten (4 KB Granularität). Laufzeit-Verifier kann Code-Integrität prüfen.

**Zu implementieren:**

1. **Compiler-Flag:** `--meta-safe` aktiviert den Pass nach dem Binary-Writer.
2. **CRC32 pro 4K-Seite:** Eigene CRC32-Implementierung (kein externe Bibliothek). Jede 4096-Byte-Seite aus `.text` wird separat gehasht.
3. **`.meta_safe`-Section:**
   - Format: Magic `0x4D455441` (4B) + PageCount (4B) + Array `{pageOffset: uint32, crc32: uint32}`
   - ELF: `SHT_NOTE`, `SHF_ALLOC | SHF_READONLY`
   - PE: Section `.meta`, `IMAGE_SCN_MEM_READ`

**Hinweis:** `std/meta_safe.lyx` existiert bereits mit `MetaSafeVerify()` und `MetaSafeGetPageHash()`. Compiler-seitiger Pass fehlt noch.

**Akzeptanzkriterien:**
- `lyxc --meta-safe hello.lyx` erzeugt Binary mit `.meta_safe`-Section
- `readelf -S out` zeigt `.meta_safe`
- `MetaSafeVerify()` = 0 bei unverändertem Binary
- Nach `dd`-Modifikation einer `.text`-Seite → `MetaSafeVerify()` = -1
