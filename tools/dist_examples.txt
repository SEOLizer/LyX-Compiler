# tools/dist_examples.txt — welche Dateien aus examples/ in die Auslieferung
# gehen. Eine Zeile je Pfad, relativ zu examples/, Reihenfolge wie im Baum.
#
# examples/ ist historisch gemischt: neben echten Beispielen liegen dort die
# Messprogramme und Bisektionsreste aus alten Fehlersuchen (test_redis_*,
# qt_fn_no_ref, glx_visual_only …). In einem Auslieferpaket sind die eine
# stille Enttaeuschung: der Nutzer haelt ein halbes Probeprogramm fuer ein
# Beispiel. Darum entscheidet DIESE Liste, nicht ein Namensmuster.
#
# tools/build_dist.sh prueft, dass jede .lyx unter examples/ entweder hier
# steht oder als Messprogramm erkennbar ist (test/debug/crash im Dateinamen).
# Jede andere Datei bricht den Lauf ab — eine neue Datei soll nicht still
# aus der Auslieferung fallen oder still hineingeraten.
