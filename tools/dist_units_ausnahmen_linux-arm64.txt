# tools/dist_units_ausnahmen_linux-arm64.txt
#
# Units, die im linux-arm64-Auslieferbaum (tools/build_dist.sh linux-arm64) FEHLEN DUERFEN,
# je mit Grund. Format:
#
#   <pfad/zur/quelle.lyx>  # <Grund, mit Issue-Nummer>
#
# Alles, was hier NICHT steht und trotzdem kein .lyu hat, macht den Lauf rot.
# Der Eintrag entschuldigt die Luecke nicht, er macht sie nur benennbar: jede
# Zeile hier gehoert in UNITS-FEHLER.txt des Baums und damit in die Hand des
# Paketbauers.
#
# Gemessen am 2026-11-14 mit lyxc 1.2.39B: 497 von 501 Units uebersetzen
# zielweise, diese vier nicht. Zwei Ursachen, beide laut gemeldet -- der
# Compiler erfindet nichts:
std/db/postgres.lyx    # select gibt es auf diesem Ziel nicht (nur pselect6 mit Signalmaske) -- #2511
std/net/ssh.lyx        # dito -- #2511
std/net/syscalls.lyx   # dito -- #2511
std/security_ext.lyx   # arch_prctl ist x86-spezifisch -- #2512
