# tests/builtin-drift-allow.txt — Builtins, die sema registriert und die der
# IR-Lowerer (src/ir_lower.lyx) NICHT kennt.
#
# Warum es diese Liste gibt (#1717): sema und ir_lower fuehren zwei Namens-
# listen, die nichts voneinander wissen. Was in sema steht, aber im Lowerer
# fehlt, uebersetzt auf dem x86-Schnellweg klaglos und bricht auf JEDEM
# IR-Ziel (arm64, riscv, lyxos, cortex-m, xtensa) mit "unbekannter Builtin/
# Funktion". Gemeldet wurde das als sechs Namen; gemessen sind es diese hier.
#
# tests/builtin_drift_test.sh vergleicht beide Listen gegen diese Datei:
#   * ein NEUER Name hier drin nicht -> Test rot (die Drift waechst)
#   * ein Name hier drin, der inzwischen gelowered ist -> Test rot
#     (Eintrag streichen, damit die Liste nicht veraltet)
# Die Liste kann also nur schrumpfen, und sie kann nicht stillschweigend
# veralten - dieselbe Bauart wie tests/known-red.txt.
#
# Ein Eintrag ist KEINE Erlaubnis, sondern ein gemessener Rueckstand.
#
# Stand: mit #1720 Block A sind zwoelf Gleitkomma-Namen abgearbeitet
# (fAdd/fSub/fMul/fDiv/fNeg/fToInt/fAbs und die fuenf Vergleiche). Offen
# bleiben dort fFloor, fCeil und fRound — sie brauchen `roundsd` (SSE4.1)
# und damit einen eigenen IR-Opcode.
