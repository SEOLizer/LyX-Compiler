# tests/lyx-geraet.txt — Tests, die ein GERAET oder einen DIENST brauchen.
#
# Gelesen von: tests/run_lyx_tests.sh
#
# Diese Tests werden UEBERSETZT, aber nicht ausgefuehrt. Das Uebersetzen bleibt
# scharf: bricht es ab, ist das ein Fehlschlag. Damit bleibt gemessen, was auf
# diesem Rechner messbar ist — die Sprache, die Signaturen, die Importe —,
# waehrend der Lauf selbst nichts aussagen koennte.
#
# WARUM NICHT known-red.txt: dort stehen DEFEKTE. Ein Test, der eine Soundkarte
# braucht und keine findet, ist keiner; er misst nur die Ausstattung des
# Rechners. In einer Liste mit echten Defekten verwaessert er die Aussage, und
# abgeraeumt wird sie dann nie (#1153).
#
# Wer einen Eintrag hinzufuegt, nennt den Grund. Wer einen entfernt, hat
# entweder das Geraet ersetzt (Attrappe, Datei statt Karte) oder den Test
# umgeschrieben.
