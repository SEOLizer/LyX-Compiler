# #1977: Klassifizierung JEDES IR-Opcodes fuer die Relokation beim Uebernehmen
# eines IR aus einer .lyu (_irUebernehmeLyu in src/ir_lower.lyx).
#
# Beim Anhaengen an ein anderes Modul verschieben sich alle Puffer. Jedes
# Feld, das in einen modulweiten Puffer zeigt, muss um dessen Basis erhoeht
# werden. WELCHES Feld das ist, haengt am Opcode — und die Belegung ist NICHT
# regelmaessig (IRO_STORE_GLOBAL traegt den Index im DEST-Feld, nicht in src1).
#
# Klassen:
#   -            keine Relokation (Slotnummern, reine Werte)
#   func:src1    src1 ist ein Index in funcBuffer
#   str:imm      imm ist ein Offset in strBuf
#   str:src2+imm src2 UND imm sind Offsets in strBuf
#   glob:src1    src1 ist ein Index in globalBuffer
#   glob:dest    DEST ist ein Index in globalBuffer
#   label:imm    imm ist eine Labelnummer (umnummerieren)
#
# Wer einen Opcode HINZUFUEGT, traegt ihn hier ein. Der Test faellt sonst aus
# — und zwar bevor jemand eine Basis auf eine Zahl addiert, die keine Adresse
# ist. Abgelesen wird am BACKEND, nicht am Kommentar in ir.lyx.
#
