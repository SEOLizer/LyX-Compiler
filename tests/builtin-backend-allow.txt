# tests/builtin-backend-allow.txt — gemessener Stand: welche Builtin-ID in
# welchem IR-Backend NICHT behandelt wird.
#
# Warum es diese Liste gibt (#2450). Es gab zwei Waechter ueber den Builtins:
# builtin_drift_test vergleicht sema gegen ir_lower (NAMEN), builtin_id_test
# vergleicht ir_lower gegen _builtin_ids.md (IDs). Keiner von beiden sieht die
# dritte Stelle, an der eine ID bekannt sein muss — das BACKEND. Genau dort
# fiel #2450 an: sema kennt den Namen, ir_lower senkt ihn, und arm64 bricht mit
# "Builtin-ID 236 wird im Linux-Zweig nicht behandelt" ab. Eine Luecke in einer
# Dimension, die kein Waechter abdeckte.
#
# Die Liste ist der gemessene Stand, kein Wunschzettel. Der Test wird rot,
#   * wenn eine NEUE Luecke dazukommt (ID in ir_lower gesenkt, Backend kennt
#     sie nicht, Zeile fehlt hier) — das ist der Fall #2450,
#   * und wenn eine Luecke zugeht, ohne dass die Zeile verschwindet (die Liste
#     soll nicht veralten).
#
# Eine Zeile hier ist eine AUSSAGE, keine Entschuldigung: "auf diesem Ziel gibt
# es diesen Aufruf bewusst nicht". Wer eine ID senkt, entscheidet damit je
# Backend, ob er sie emittiert oder ihr Fehlen hier eintraegt.
#
# Format:  <ID>\t<Name(n) aus ir_lower>\t<Backends ohne Behandlung>
#
# Die grosse Masse sind die ZIELGEBUNDENEN lyxos-Syscalls (Bereich 20…256):
# nur `lyxos` emittiert sie, auf arm64/riscv/arm-cm/xtensa haben sie keine
# Bedeutung. Das ist richtig so und bleibt es; die Zeile haelt nur fest, dass
# es eine Entscheidung war. Dass die MELDUNG auf anderen Zielen die Ursache
# nicht nennt, ist #2427 und wird dort behoben, nicht hier.
#
# Die uebrigen Luecken, nach Grund:
#   * arm_cm und xtensa sind bewusst duenn (#1388, #1281) — kein Dateisystem,
#     keine Argumente, keine Gleitkommaausgabe.
#   * 12 (`Printf`) fehlt auf riscv, lyxos, arm-cm, xtensa (#1388, #1715).
#   * 7/8 (`StrConcat`/`StrCopy`) und 10/11 (Barrieren) fehlen auf lyxos
#     (#1715).
#   * 568 (`sha256_compress`) fehlt in JEDEM IR-Backend: x86 emittiert es
#     direkt (#2391), die IR-Ziele noch nicht. Fuer lyxos ist das #2438.
#   * 236 (`rmdir`) fehlt auf arm64 — das ist #2450 selbst: `import std.fs`
#     reichte, weil die Unit den Aufruf mitbringt, auch wenn ihn niemand ruft.
#     Seit #2451 wird toter Code nicht mehr emittiert, die Luecke in der ID
#     bleibt aber. Die Zeile verschwindet, sobald der Fix drin ist, und der
#     Test wird rot, wenn sie vergessen wird.
#
# Erhoben mit tests/builtin_id_test.sh (Pruefung 3); dort steht auch, wie die
# Behandlung je Backend erkannt wird.
