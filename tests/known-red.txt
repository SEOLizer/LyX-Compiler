# tests/known-red.txt — Tests, die laufen, aber bekannt rot sind.
#
# Warum es diese Liste gibt: ein roter Test, der aus einem Ziel entfernt wird,
# damit das Ziel gruen wird, ist danach unsichtbar — genau der Verfall, den
# #1004 und #1112 aufgedeckt haben. Eintraege hier laufen weiter mit, brechen
# das Ziel aber nicht ab.
#
# Regeln:
#   * Jeder Eintrag traegt ein Issue. Ohne Issue verschwindet der Defekt.
#   * Wird ein Eintrag wieder gruen, meldet der Runner das und das Ziel wird
#     ROT. Die Liste kann also nicht stillschweigend veralten.
#   * Pfad relativ zur Repo-Wurzel, ein Eintrag je Zeile, `#` beginnt einen
#     Kommentar.
#
# Gelesen von: tests/run_lyx_tests.sh (tests/lyx/**), Ziel `test-known-red`
# im Makefile (die .sh-Eintraege).
