# tests/builtin-id-geteilt.txt — Builtin-IDs, die MEHRERE Namen senken duerfen.
#
# Warum es diese Liste gibt (#2432). Die ID im IRO_CALL_BUILTIN-Befehl ist der
# Schluessel, ueber den jedes Backend den Builtin wiedererkennt
# (`else if id == 564 { … }`). Zwei Builtins mit derselben ID heisst: das
# Backend fuehrt den erstpassenden Zweig aus — kein Abbruch, kein Hinweis, ein
# falsches Ergebnis. Beim Bauen von #2391 war die 567 fast doppelt vergeben
# (`fma` seit #2403, dazu neu `sha256_compress`); aufgefallen ist es nur, weil
# die vergebenen IDs von Hand erhoben wurden. builtin_drift_test blieb gruen:
# beide Namen standen in sema UND in ir_lower, die Doppelung der ID sah er
# nicht.
#
# Eine geteilte ID ist erlaubt, wenn die Namen DIESELBE Operation brauchen —
# `PrintStr` und `PrintLn` werden beide zu `write(1, ptr, len)`. Die ID benennt
# die emittierte Operation, nicht den Namen im Quelltext
# (src/backend/_builtin_ids.md, Kopf des Abschnitts "Allgemeine IDs").
#
# Genau diese Faelle stehen hier. Jede andere Mehrfachvergabe macht
# tests/builtin_id_test.sh rot.
#
# ZU DEN NAMEN IN DEN KOMMENTAREN. Unterhalb von 20 steht je Senkung ein
# eigener seq()-Vergleich, die Zuordnung ist eindeutig. Darueber wird die ID
# oft ueber eine Weiche vergeben (`var a1id := 221; if seq("mkdir") { a1id :=
# 226; }`); der Test nennt dann alle Namen des Blocks, auch solche, die einen
# anderen Zweig meinen. Die Kommentare hier nennen deshalb die OPERATION —
# sie ist das, worueber der Eintrag eine Aussage macht. Gezaehlt und geprueft
# wird die ID.
#
# Format:  <ID>  # <Operation> — <Namen>
1    # write(1, ptr, len)              — PrintStr, PrintLn
2    # Ganzzahl nach stdout            — PrintInt, PrintLn
6    # Teilzeichenkette                — StrSub, StrSplit
13   # write(2, ptr, strlen(ptr))      — EPrint, panic
14   # Zeilenumbruch nach stderr       — EPrintLn, EPrintStrLn
15   # Laenge einer Zeichenkette       — StrLen, EPrintInt, StrSplit
16   # Ganzzahl als Dezimaltext        — IntToStr, EPrintInt
18   # Zeiger auf den Argumentvektor   — GetArgV, GetArg
188  # LyxOS 316 FUTEX_WAIT            — sys_futex_wait und der WAIT-Zweig des
     #                                   multiplexten sys_futex (#1810)
189  # LyxOS 317 FUTEX_WAKE            — sys_futex_wake und der WAKE-Zweig des
     #                                   multiplexten sys_futex (#1810)
200  # Byte lesen                      — peek8, buf_get_byte, StrSplit, StrEqual,
     #                                   Indexzugriff a[i]
201  # 32 Bit lesen                    — peek32, peek32f
202  # 64 Bit lesen                    — peek64, peekf64, GetArg, ArgvGetStr
203  # Byte schreiben                  — poke8, buf_put_byte, StrSplit, FileReadAll
204  # 32 Bit schreiben                — poke32, poke32f
205  # 64 Bit schreiben                — poke64, pokef64, StrSplit
220  # open(pfad, flags, mode)         — open; FileReadAll und FileSize oeffnen
     #                                   ihre Datei damit (#2266)
221  # close(fd)                       — close; FileReadAll und FileSize schliessen
     #                                   damit (#2266)
222  # read(fd, buf, n)                — read; FileReadAll liest damit (#2266),
     #                                   getdents64 ist auf LyxOS read-on-dirfd
223  # write(fd, buf, n)               — write; EPrintInt gibt darueber aus
228  # lseek(fd, off, whence)          — lseek; FileReadAll und FileSize messen
     #                                   damit die Groesse (#2266)
404  # Zeichenketten auf Gleichheit    — StrEquals, StrEq
547  # newfstatat (Nr. 79)             — stat, lstat, sys_newfstatat; Unterschied
     #                                   ist nur das Flag AT_SYMLINK_NOFOLLOW (#2156)
